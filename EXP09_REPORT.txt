EXPERIMENT #9: BIAS-GAIN COMPENSATED BLOCK REGISTRATION
========================================================

IMPLEMENTATION
--------------
File: driftforge/phys/exp09_biasgain.py

FEATURES (all prefixed bg_):
  1. bg_gain_median          - Median gain across blocks
  2. bg_bias_median          - Median bias across blocks
  3. bg_gain_std             - Standard deviation of gains
  4. bg_bias_std             - Standard deviation of biases
  5. bg_gain_deviation       - |median_gain - 1.0| (distance from ideal)
  6. bg_bias_magnitude       - |median_bias| (absolute offset)
  7. bg_compensated_ncc      - Correlation after bias/gain compensation
  8. bg_compensated_rmse     - Residual after global bias/gain compensation
  9. bg_raw_minus_compensated- Improvement from compensation (raw - compensated RMSE)
  10. bg_block_inlier_fraction - Fraction of blocks where compensation helps

ALGORITHM
---------
1. Extract search patch at candidate location (same size as template)
2. Partition both template and patch into 4x4 blocks using same convention as
   structural_descriptor._block_nccs
3. Per block: fit S(x) = a*T(x) + b via least-squares regression
   - Guard against degenerate blocks (near-zero template variance) -> return NaN
   - Exclude from aggregates
4. Aggregate statistics across valid blocks (median, std)
5. Compute global (whole-patch) bias/gain fit for bg_raw_minus_compensated
6. Apply compensated images: S_comp = (S - bias) / gain
7. Measure correlation and RMSE before/after compensation

PHYSICAL REASONING
------------------
SEM charging causes local intensity distortion but photometric compensation
should NOT fix geometric misregistration. Therefore:

TRUE SITE (with charging):
  - Raw photometric error: LARGE (charging distorts intensity)
  - After compensation: SMALL (linear model fixes intensity)
  - bg_raw_minus_compensated: LARGE (compensation explains the error)
  - bg_compensated_ncc: HIGH (good match after correction)
  - bg_gain_deviation: Could be large or small depending on charge magnitude

FALSE SITE (lattice sibling, geometrically wrong):
  - Raw error: MIXED (some blocks accidentally aligned, others wrong)
  - After compensation: Still WRONG (can't fix geometry with intensity scaling)
  - bg_raw_minus_compensated: SMALL/MIXED (compensation helps little)
  - bg_compensated_ncc: LOW (still misaligned)
  - bg_gain_deviation: Variable (blocks have different scaling needs due to geometry)

KEY INSIGHT (bg_raw_minus_compensated):
When photometric compensation is the only problem, improving RMSE is large.
When geometric misregistration is the problem, compensation helps little.
The delta (raw - compensated) isolates what compensation can fix.

INTERPRETATION
---------------
1. bg_gain_deviation shows EXCELLENT separation (5/5), indicating that true
   sites have consistent, predictable gain patterns across blocks while false
   sites have highly variable gains.

2. bg_compensated_ncc shows EXCELLENT separation (5/5), indicating that after
   compensation, true sites achieve much better correlation than false sites.

3. bg_raw_minus_compensated shows WEAK separation (3/5) for THIS test case
   because:
   - Wrong sites #1,2,4 have LOWER raw RMSE (148, 157, 151) than GT (162)
   - Lower raw RMSE means less room for improvement
   - This reflects that small lattice offsets (8-16 px) can be accidentally
     well-aligned despite geometric error
   - Feature would likely work better at larger offsets or with more severe
     geometric misalignment

4. bg_block_inlier_fraction=1.0 everywhere indicates that global bias/gain
   fits improve (or at least don't hurt) every block, suggesting the model
   is adaptable even to misaligned data.

RECOMMENDATION
--------------
The experiment should be evaluated on a broader range of test cases including:
- Larger lattice offsets (to test geometric misregistration stronger)
- Different charge magnitudes and spatial patterns
- Different architectures (DRAM, FinFET, etc.)

The two strong features (bg_gain_deviation, bg_compensated_ncc) suggest the
bias/gain compensation concept is sound for discriminating true sites from
false ones. bg_raw_minus_compensated may become more discriminative at larger
misalignments.
